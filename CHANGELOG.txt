여러 파일 다운로드 허용이 필요할 수 있습니다. 탭을 닫기 전에 녹화 중지·저장을 누르세요.

이 기능은 별도 화면 공유 권한을 요청하는 화면 녹화가 아니라 플레이어 영상 캡처를 사용합니다.

검증: 두 체크 조건, 설정 보존, 중복 시작 방지, 5분 분할 저장 후 재시작 모의 테스트 통과.
실제 웨일에서 방송 시작/자동재생/파일 저장까지의 연동은 미검증입니다.

치지직 올인원 1.4.9.10: 자동 탭 열기 채널 체크박스

시스템 > 방송 시작 시 자동 탭 열기를 켠 뒤 팔로우 목록 불러오기를 누르세요.
원하는 채널을 체크하면 즉시 저장됩니다. 검색할 수 있으며 기존 등록 채널도 유지합니다.
선택 0개는 자동 열기 없음입니다. 알림 제외/자동 새로고침 설정과는 별개입니다.
같은 브라우저에서 치지직 로그인이 필요합니다. 목록은 최대 300개를 요청하며,
누락된 채널은 기존 URL/ID 입력으로 등록할 수 있습니다.
실제 로그인 환경에서 목록 API 호출 및 방송 시작 연동은 미검증입니다.

치지직 올인원 1.4.9.9 사이드바 미리보기 전용판

미리보기 변경
사이드바 방송 미리보기만 유지합니다. 본문 썸네일 미리보기는 기존 설정과
관계없이 차단하며, 설정 화면과 초기 설정 마법사에서 해당 항목을 숨깁니다.
레이턴시 보정과 Tampermonkey 화질 관리 방식은 이전 버전과 같습니다.

화질 변경은 Tampermonkey에서 관리합니다.
이 버전은 자동/수동 화질 변경, 강제 재적용, 저지연 트랙 선택 명령을
차단합니다. 기존 화질 설정이 켜져 있어도 실행하지 않습니다.

업데이트
새 INSTALL-THIS 안의 내용을 기존에 등록한 INSTALL-THIS에 덮어쓰고,
웨일 확장앱 관리에서 새로고침을 누릅니다. 방송 탭도 닫았다가 새로 엽니다.

설정
확장 설정에서 '목표 레이턴시'를 3초로, '추격 방식'을 '즉시'로 설정합니다.
목표 0은 비활성화입니다. UI 검색창에 '레이턴시'를 입력해 찾을 수 있습니다.
네이티브 저지연 우선이나 재생 속도 UI 토글과 독립적으로 작동합니다.
즉시는 목표보다 뒤처지면 seekable 범위 안의 목표 위치로 이동합니다.
점진적은 1.05~1.10배속으로 따라잡고, 8초 이상 크게 뒤처지면 이동합니다.
위치 이동은 두 번 연속 지연 확인 후, 최소 10초 간격으로 제한합니다.
목표에 도달하면 자동으로 적용한 배속만 1배속으로 복귀합니다.

보호 동작
일시정지·탐색·직접 되감기·수동 배속·다시보기에서는 자동 추격을 멈춥니다.
사용자 되감기 후 추격을 재개하려면 라이브 이동 기능 또는 새로고침을 사용합니다.
버퍼가 부족하면 배속을 올리지 않으며, 찾을 수 없는 재생 범위로 이동하지 않습니다.
목표 1초 미만은 1초로 제한합니다. 실제 달성 가능한 지연은 스트림에 좌우됩니다.

원인 및 수정
이전 React 호환 경로는 지연을 표시만 하고 기존 추격 루프를 연결하지 않았습니다.
이번에는 영상의 실제 seekable/currentTime/playbackRate로 추격을 처리합니다.
기존 설정 스키마의 'instant' 값과 예전 처리 코드의 'immediate' 불일치도 처리합니다.
Tampermonkey가 SDK를 교체해도 같은 영상 요소라면 연결 정보를 갱신합니다.

중요한 구분
화면의 '라이브 지점과 차이'는 제공된 영상 끝과 현재 재생 위치의 차이입니다.
방송 원본/전송단에서 발생하는 지연까지 제거하거나 측정하는 수치는 아닙니다.
네이티브 저지연 스트림 모드를 강제로 변경하지 않습니다.

검증
재현 테스트 통과: 29초→3초 이동, 점진적 보정, 목표 도달/비활성 시 복원,
일시정지/되감기/수동 배속 보호, 다시보기 제외, 버퍼 보호, 이벤트 정리,
화질 명령 차단. 실제 웨일 방송에서의 이번 버전 동작은 미검증입니다.
node compatibility/latency-controller.test.mjs
전체 npm 빌드는 미수행이며 INSTALL-THIS는 원본 빌드에 호환 모듈을 연결한 파일입니다.

1.4.9.9 추가 수정
설치용 번들의 광범위한 _content_ 사이드바 판별을 제거했습니다.
카드 표시 직전에도 사이드바 안의 링크인지 검사합니다.
본문 호버 카드 확대를 차단하고 사이드바 미리보기는 유지합니다.
