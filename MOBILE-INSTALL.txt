치지직 올인원 · 모바일 통나무 1.0.4 시험판

대상: 안드로이드용 Quetta 브라우저
공식 다운로드 안내: https://www.quetta.net/
모바일 웨일/모바일 Chrome/치지직 공식 앱에는 이 ZIP을 설치할 수 없습니다.

설치
1. 공식 안내를 통해 Quetta를 설치합니다.
2. 이 ZIP 파일을 휴대폰에 다운로드합니다. ZIP 안에 다른 설치 ZIP은 없습니다.
3. Quetta의 확장프로그램 관리 화면에서 로컬 ZIP 설치/가져오기 항목으로 이 파일을 선택합니다.
   메뉴 명칭과 위치는 앱 버전에 따라 다를 수 있습니다.
   ZIP 가져오기 항목이 없다면 메뉴 화면을 확인해야 합니다. PC 개발자모드 메뉴와 같다고 가정하지 마세요.
4. 확장프로그램을 활성화하고 치지직 사이트에서 실행되도록 허용합니다.
5. Quetta에서 https://m.chzzk.naver.com/ 에 로그인하고 라이브 방송을 엽니다.
6. 오른쪽 아래의 🪵 버튼을 누르면 자동 수령 스위치, 위치 변경, 보유량 확인, 수령 기록이 나옵니다.
7. 기존 PC용 확장프로그램을 같은 브라우저에 중복 설치하지 마세요.

포함 기능
- 서버에서 읽은 통나무 보유량 (30초 간격)
- 서버가 현재 채널에 발급한 WATCH_1_HOUR 보상만 자동 수령 (기본 켜짐)
- 수령 성공 응답을 확인한 기록, 최대 100건 저장/최근 10건 화면 표시
- 적립 알림 확인 / 확인 중 / 대기 추정 상태 구분
- 터치 설정, 위·아래 표시 위치, 채널 이동 대응

이 파일은 PC 1.4.9.55의 통나무 상태 모듈을 바탕으로 만든 별도 모바일 배포본입니다.
전체 올인원 기능의 모바일 이식판은 아닙니다.
녹화, 자동 방송 열기, 화질 고정, 배너 변경, 광고/P2P 기능은 포함하지 않습니다.
모바일 로그인·설정·기록은 PC 브라우저와 별개입니다.

첫 확인
- 한 채널만 열고 로그인된 상태로 시청합니다. 다른 기기의 같은 계정 방송은 잠시 종료합니다.
- 6~10분 후 서버 보유량이 늘어나는지 확인합니다. 확장이 보유량을 늘리는 것은 아닙니다.
- '적립 확인 중'은 미적립 판정이 아닙니다. 모바일 웹에서 적립 알림을 받을 수 없으면 계속 표시될 수 있습니다.
- '벌목중 · 적립 확인'은 최근 WATCH_5_MIN 서버 알림이 확인됐다는 뜻이며, 현재의 연속 적립을 보장하지 않습니다.
- '벌목대기중 · 추정'은 재생 또는 이 브라우저의 탭 상태 기준입니다. 다른 기기의 수급 상태까지 알 수는 없습니다.
- 1시간 보상이 실제로 생긴 뒤 기록과 잔액을 확인합니다.
- 보유량이 늘지 않으면 브라우저의 PC 사이트 보기와 패널의 PC 웹 주소를 함께 사용해 비교합니다.
  PC 주소만 눌러서는 모바일 리디렉션을 막지 못할 수 있습니다.

제한과 확인 범위
- 서버가 발급한 보상만 받으며 시청 시간을 생성하거나 조건을 우회하지 않습니다.
- 모바일 웹에서 실제 시청 시간이 집계되는지, API 인증이 유지되는지, Quetta에서 설치되는지는 실기기 검증 전입니다.
- 화면 잠금, 절전, 브라우저 종료, 백그라운드 정지 시 확인과 수령이 멈출 수 있습니다.
- 전체화면에서는 버튼이 가려지지 않도록 확장 UI를 숨깁니다. 전체화면 해제 시 다시 표시됩니다.
- 확장프로그램의 보상 요청은 치지직 웹에서 사용하는 비공개 API를 따릅니다. 치지직 변경 시 수정이 필요할 수 있습니다.
- 로그인/요청 오류는 패널에 표시하며 실패를 성공 기록으로 남기지 않습니다.
- API 응답 실패 시 짧은 시간에 재요청하지 않습니다. 보유량 확인 버튼도 서버 요청 제한(30초)을 따릅니다.

검증
11개 자동 검사 통과: 중복 수령 억제, 스위치 OFF, 실패 로그 제외, 채널 검증,
잘못된 보상 ID 제외, 서버 적립 알림 우선, 오래된 알림/페이지 이동 처리.
실기기·로그인된 실제 방송·화면 렌더링은 확인하지 못했습니다.


1.0.1 획득 로그 수정
- 1.0.0은 1시간 자동 수령 처리만 기록하여 일반 적립 내역이 비어 있었습니다.
- 이제 보유량 조회 사이의 순변동을 획득·사용 로그에 저장합니다(최대 100건/최근 30건 표시).
- 자동 수령 스위치가 꺼져 있어도 보유량 변동은 기록됩니다.
- 일반 시청/후원/승부예측을 잔액만으로 구별하지 않으며 '5분 시청 보상'으로 단정하지 않습니다.
- 첫 조회는 기준 잔액만 저장합니다. 이후 실제 잔액이 변하면 최대 약 30초 뒤 표시됩니다(브라우저 실행 중 기준).
- 오래된 조회와 비교한 결과는 '조회 공백 동안 순변동'으로 구별합니다.
- 1시간 자동 수령 처리 내역은 별도 목록입니다. 잔액 변동과 합산하지 않습니다.
- 수령 응답의 최종 잔액을 보상량으로 잘못 표시하던 문제도 수정했습니다.
- 패널을 열어 둔 상태에서도 로그가 자동 갱신됩니다.
- 업데이트 전에 기록하지 않았던 과거 적립은 복구할 수 없습니다.

업데이트
Quetta 확장 관리에서 기존 항목을 업데이트하는 ZIP 설치 기능이 있으면 이를 이용하고 버전 1.0.1을 확인하세요.
별도 항목으로 설치됐다면 1.0.0을 비활성화하고 1.0.1만 사용하세요. 별도 설치의 기록은 이전 항목과 공유되지 않을 수 있습니다.
업데이트 후 치지직 방송 페이지를 새로고침하세요. 기존 확장 삭제 시 기존 설정/로그도 지워질 수 있습니다.

1.0.2 연결·버튼 호환 수정 (2026-11-23)
- 모바일 확장 API의 콜백/Promise 응답 방식을 모두 지원합니다.
- 응답이 없으면 25초 후 조회 대기를 해제하여 다시 확인할 수 있습니다.
- 연결 상태, 조회 오류, 마지막 잔액 확인을 구분하고 페이지 새로고침 버튼을 추가했습니다.
- 화면에 표시되는 버전은 1.0.2입니다. 이전 버전은 끄고 치지직 탭을 닫았다가 다시 여세요.
- 벌목중은 시청 적립 알림이며, 1시간 보상의 수령 성공을 뜻하지 않습니다. 자동 수령 처리 내역과 보유량 변화를 확인하세요.
- 코드 기반 검사 16개 통과. 실제 Quetta 기기의 터치·실방송 수령은 미검증입니다.


1.0.3 방송 이동 후 연결 수정 (2026-11-23)
- 홈→방송, 방송→다른 방송 이동 시 이전 문서 주소와 현재 방송 주소 불일치로 요청을 응답 없이 거절하던 조건 수정.
- 허용된 치지직 출처와 채널 ID 형식 검증은 유지하며 현재 화면이 요청한 채널을 조회합니다.
- 기존 버전에서 위 두 경로의 실패를 모의 재현하고 수정 후 통과 확인. 전체 코드 검사 18개 통과.
- 실제 Quetta 홈 화면 바로가기에서 재현·해결 여부는 미검증입니다.
- 업데이트 후 기존 모바일판을 끄고 치지직 탭을 닫았다가 다시 여세요. 패널 제목 1.0.3 확인.

1.0.4 공식 1시간 보상 버튼 수령 (2026-11-24)
- 자동 수령 ON 상태에서 화면의 '1시간 시청 통나무 파워 배달 완료! … 받기' 버튼을 감지하면 공식 클릭 동작을 실행합니다.
- 배너가 보이면 보유량 API 목록 기반 수령 대신 공식 버튼을 사용하여 같은 조회에서 중복 요청하지 않습니다.
- 해당 채널의 실제 수령 PUT 성공 응답(code 200 및 결과 잔액)을 확인해야 자동 수령 내역을 저장합니다. 클릭·애니메이션만으로 성공 처리하지 않습니다.
- 통신 실패/15초 무응답은 성공으로 기록하지 않으며 재시도 간격은 60초입니다. 잔액 순변동 기록과 수령 내역을 합산하지 마세요.
- 수령 내역을 잔액 로그 위로 이동했습니다.
- 모의 검사 25개 및 문법 검사 통과. 실제 Quetta 기기의 1시간 보상 수령은 미검증입니다.
- 업데이트 후 이전 모바일판은 끄고 치지직 탭을 닫았다가 다시 여세요. 제목 1.0.4 확인.
