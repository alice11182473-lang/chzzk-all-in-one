## 확장 설치 및 업데이트

1. 위 ZIP을 다운로드하고 **전체 압축을 해제**합니다.
2. 웨일은 `whale://extensions`, 크롬은 `chrome://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 눌러 ZIP 안의 **INSTALL-THIS** 폴더를 선택합니다. ZIP 전체 폴더나 `source` 폴더를 선택하지 않습니다.
4. 기존 사용자는 녹화를 모두 정지하고 저장 완료를 기다린 다음, 기존 등록 폴더에 `INSTALL-THIS` 내부 파일을 덮어씁니다. 확장 관리에서 새로고침하고 치지직 페이지도 새로고침합니다.
5. 확장 관리 화면에서 버전 `1.4.9.48`을 확인합니다. 기존 폴더를 계속 사용하면 확장 ID와 설정 유지에 유리합니다.

ZIP 구성: `INSTALL-THIS/`는 설치 번들, `source/`는 소스 및 테스트, `NATIVE-RECORDER/`는 Windows 녹화 보조 프로그램입니다. 저장소에서는 이 폴더 구조를 ZIP으로 배포합니다.

## 녹화 시작하기

**원본 녹화를 처음 사용한다면 확장 설치 외에 Windows 보조 프로그램 설치가 필요합니다.**

1. Python 3.10 이상을 준비합니다. [Windows용 Python](https://www.python.org/downloads/windows/)을 설치할 때 Python launcher 또는 PATH 등록을 사용하세요. 설치 도우미는 `py -3`, `python` 순서로 확인합니다.
2. 확장 설정 → **미디어 → 원본 스트림 녹화 → 확장 ID 복사**를 누릅니다.
3. 압축을 푼 `NATIVE-RECORDER/INSTALL.cmd`를 실행하고 ID를 붙여넣습니다.
4. 패키지 설치 후 나타나는 창에서 녹화 기본 저장 폴더를 고릅니다.
5. 확장 설정에서 **원본 녹화 연결 확인**을 누르고 연결 성공 여부를 확인합니다.
6. 방송 페이지의 녹화 버튼으로 시작하고, 같은 버튼 또는 설정의 **정지 / 전체 녹화 정지**로 종료합니다.

자세한 자동 녹화 설정, 저장 경로, 업데이트와 문제 해결은 **[녹화 사용 안내](./RECORDING.md)**를 확인하세요.

## 주요 녹화 설정

| 설정 | 동작 |
| --- | --- |
| 녹화 형식 | MP4 기본, MKV 선택 가능 |
| 녹화 저장 폴더 | 설치 시 선택한 기본 폴더 아래의 하위 경로. 빈칸이면 기본 폴더 |
| 방송 시작 시 자동 탭 열기 | 시스템 탭에서 켜고 대상 채널을 선택 |
| 채널별 자동 열기 + 녹화 | 두 스위치가 모두 켜진 채널은 생방 감지 시 탭 열기와 원본 녹화 시작 |
| 자동 열기 후 원래 탭 복귀 | 기본 꺼짐. 켜면 시작 확인 후 이전 탭으로 복귀 |
| 녹화 진단 복사 | 연결 상태·작업 상태·오류 확인. 녹화 폴더에는 로그 파일을 생성하지 않음 |

원본 녹화는 Streamlink로 방송을 받고 FFmpeg로 **재인코딩 없이 저장**합니다. 플레이어 화면 필터·볼륨·배속과 녹화본은 별개입니다. 녹화 품질은 수신 가능한 최상위 스트림(`best`)을 사용합니다.

## 1.4.9.48 변경 사항

- 모아보기 패널 최소 높이 120px → 72px: 아래쪽 점선을 위로 끌어 기본 글꼴 채팅 한 줄 정도까지 축소 가능
- 조절한 높이는 새로고침 후에도 유지

### 1.4.9.47에서 이어지는 변경

- 채팅 모아보기 헤더·목록 탐색에 CSS 해시를 사용하지 않는 대체 탐색 추가
- 더보기 메뉴를 찾지 못해도 분리 패널 표시 처리
- 중첩된 메뉴 구조에서도 모아보기·내보내기 버튼 삽입 처리

### 1.4.9.46에서 이어지는 변경

- 채팅·필터 설정에 **채팅 모아보기 사용** 스위치 추가
- 모아보기 활성화/조건 변경 시 기존 채팅 재검사
- 채팅의 React 데이터가 늦게 준비되는 경우 재시도
- 기존 원본 녹화, 로그 파일 미생성, 자동 열기 후 원래 탭 복귀 선택 기능 유지

이미 보조 프로그램 1.4.9.45를 설치했다면 이번 1.4.9.48 업데이트는 확장 파일만 교체하면 됩니다. 그보다 이전 보조 프로그램은 녹화를 모두 정지한 뒤 `INSTALL.cmd`도 다시 실행하세요.

## 검증과 제한

코드 테스트 및 Linux FFmpeg를 이용한 합성 영상 MP4/MKV 저장·수동 정지 테스트를 수행했습니다. 실제 Windows/웨일 실방송 환경에서 장시간 무중단 동작을 보장하지 않습니다. 소스와 설치 번들을 함께 수정했으며 전체 재빌드는 하지 않았습니다.

로그인·성인·권한 제한 방송은 녹화 연결에 실패할 수 있습니다. 브라우저 쿠키는 추출하지 않습니다. 브라우저 전체 종료 또는 확장 업데이트 전에는 녹화를 정지하고 파일 마무리를 기다려 주세요.
