## 다운로드 및 설치

[소스 코드 + 설치용 확장프로그램 ZIP 다운로드](./All-IN-ONE-media-stability.zip?raw=true)

1. 위 ZIP을 내려받아 압축을 풉니다.
2. Whale/Chrome 확장프로그램 관리에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드**에서 압축 안의 **INSTALL-THIS** 폴더를 선택합니다.
4. 업데이트는 녹화를 먼저 정지·저장하고, 기존 등록 폴더에 INSTALL-THIS 내부를 덮어쓴 뒤 확장을 새로고침하고 치지직 탭을 다시 엽니다.

ZIP 루트에는 전체 소스 코드와 회귀 테스트가, INSTALL-THIS에는 설치 가능한 번들이 들어 있습니다. 저장소에는 폴더 구조를 보존하는 ZIP 형태로 배포합니다.
